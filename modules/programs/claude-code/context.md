## Memory and context files

- Save only what I state as standing: "always", "from now on", "in every repo", or a correction of how you work in general.
- A direction for one task, agent or session ("keep this PoC simple", "loose permissions here", "run it for me") is not a preference. Don't save it to memory or write it into CLAUDE.md, AGENTS.md, a skill or any other context file.
- Don't turn your own lessons from a session into rules either, unless I ask.
- Unsure whether something is standing? Ask before saving it.
